# প্রজেক্ট সামারি: BuddyScript Frontend

এই ডকুমেন্টে আমার BuddyScript প্রজেক্টের frontend অংশের সম্পূর্ণ স্ট্রাকচার এবং প্রতিটি ফাইলের কাজ এবং উদ্দেশ্য বিস্তারিতভাবে বর্ণনা করা হয়েছে। এটি একটি React-based সোশ্যাল মিডিয়া অ্যাপ্লিকেশন যা TypeScript, Vite, এবং বিভিন্ন UI লাইব্রেরি ব্যবহার করে তৈরি।

## প্রজেক্ট ওভারভিউ

এই প্রজেক্টটি একটি সোশ্যাল মিডিয়া প্ল্যাটফর্মের frontend অংশ। এখানে ব্যবহারকারীরা পোস্ট তৈরি করতে পারেন, কমেন্ট করতে পারেন, লাইক দিতে পারেন, এবং তাদের প্রোফাইল ম্যানেজ করতে পারেন। প্রজেক্টটি React Router ব্যবহার করে রাউটিং করে এবং TanStack React Query ব্যবহার করে ডেটা ম্যানেজমেন্ট করে।

## প্রধান ফোল্ডার স্ট্রাকচার

```
src/
├── main.tsx              # অ্যাপ্লিকেশনের এন্ট্রি পয়েন্ট
├── App.tsx               # মূল অ্যাপ কম্পোনেন্ট
├── contexts/             # React Context API ব্যবহার করে গ্লোবাল স্টেট ম্যানেজমেন্ট
├── types/                # TypeScript টাইপ ডেফিনিশন
├── utils/                # ইউটিলিটি ফাংশন এবং হেলপার
├── services/             # API কল এবং ব্যাকেন্ড কমিউনিকেশন
├── pages/                # পেজ কম্পোনেন্ট (রাউট)
├── components/           # রিইউজেবল কম্পোনেন্ট
└── assets/               # স্ট্যাটিক অ্যাসেট
```

## মূল এন্ট্রি ফাইল

### main.tsx
এটি অ্যাপ্লিকেশনের প্রধান এন্ট্রি পয়েন্ট। এখানে:
- React এবং React DOM ইমপোর্ট করা হয়
- BrowserRouter সেটআপ করা হয় রাউটিং এর জন্য
- QueryClient প্রোভাইড করা হয় ডেটা ফেচিং এর জন্য
- AuthProvider প্রোভাইড করা হয় অথেন্টিকেশন স্টেট ম্যানেজমেন্ট এর জন্য
- সব রাউট ডিফাইন করা হয় (লগিন, রেজিস্টার, ফিড, প্রোফাইল ইত্যাদি)

### App.tsx
এটি একটি সিম্পল কম্পোনেন্ট যা শুধু `<Outlet />` রিটার্ন করে। এটি React Router এর জন্য ব্যবহার হয় যাতে nested রাউট রেন্ডার হতে পারে।

## Contexts (গ্লোবাল স্টেট ম্যানেজমেন্ট)

### AuthContext.tsx
এটি অথেন্টিকেশন স্টেট ম্যানেজ করার জন্য। এখানে:
- ব্যবহারকারীর লগিন স্টেট, টোকেন, এবং তথ্য সংরক্ষণ করা হয়
- login, register, logout ফাংশন প্রোভাইড করা হয়
- টোকেন এক্সপায়ার হলে অটোমেটিক লগআউট করে
- localStorage এ টোকেন এবং ইউজার ডেটা স্টোর করে

## Types (TypeScript টাইপ ডেফিনিশন)

### auth.ts
অথেন্টিকেশন সম্পর্কিত টাইপ ডেফিনিশন:
- LoginCredentials: লগিন এর জন্য email এবং password
- RegisterCredentials: রেজিস্ট্রেশন এর জন্য first_name, last_name, email, password, password_confirmation
- User: ব্যবহারকারীর তথ্য (id, first_name, last_name, email)
- AuthResponse: API রেসপন্স এর জন্য user এবং token

## Utils (ইউটিলিটি ফাংশন)

### RegistrationValidation.ts
ফর্ম ভ্যালিডেশন এর জন্য ইউটিলিটি ফাংশন:
- validatePassword: পাসওয়ার্ড স্ট্রেন্থ চেক করে (8 ক্যারেক্টার, uppercase, number, special character)
- validateEmail: ইমেইল ফরম্যাট ভ্যালিডেট করে
- validatePasswordMatch: কনফার্ম পাসওয়ার্ড ম্যাচ করে
- validateRequired: ফিল্ড খালি কিনা চেক করে

## Services (API কমিউনিকেশন)

### authService.ts
অথেন্টিকেশন API কল ম্যানেজ করে:
- login: ব্যবহারকারী লগিন করে
- register: নতুন ব্যবহারকারী রেজিস্টার করে
- logout: লগআউট করে
- token ম্যানেজমেন্ট (localStorage এ স্টোর/রিমুভ)
- verifyToken: টোকেন ভ্যালিড কিনা চেক করে

### commentService.ts
কমেন্ট ম্যানেজমেন্ট এর জন্য:
- getCommentsByPost: একটি পোস্টের সব কমেন্ট ফেচ করে
- createComment: নতুন কমেন্ট তৈরি করে (রিপ্লাই সহ)
- updateComment: কমেন্ট এডিট করে
- deleteComment: কমেন্ট ডিলিট করে
- toggleCommentLike: কমেন্টে লাইক/আনলাইক করে
- getCommentLikes: কমেন্টের লাইক লিস্ট পায়

### likeService.ts
লাইক ম্যানেজমেন্ট এর জন্য:
- toggleLike: পোস্ট বা কমেন্টে লাইক/আনলাইক করে
- getLikes: লাইক লিস্ট পায়

### postService.ts
পোস্ট ম্যানেজমেন্ট এর জন্য:
- getAllPosts: সব পোস্ট ফেচ করে
- getPostsPaginated: পেজিনেশন সহ পোস্ট ফেচ করে
- createPost: নতুন পোস্ট তৈরি করে (ইমেজ আপলোড সহ)
- getPost: একটি পোস্টের ডিটেল পায়
- updatePost: পোস্ট এডিট করে
- deletePost: পোস্ট ডিলিট করে

### userService.ts
ইউজার ম্যানেজমেন্ট এর জন্য:
- updateProfile: প্রোফাইল আপডেট করে
- updatePassword: পাসওয়ার্ড চেঞ্জ করে

## Pages (রাউট কম্পোনেন্ট)

### AuthLayout.tsx
অথেন্টিকেশন পেজের লেআউট। লগিন এবং রেজিস্ট্রেশন পেজের জন্য কমন ব্যাকগ্রাউন্ড এবং স্ট্রাকচার প্রোভাইড করে।

### Feed.tsx
মূল ফিড পেজ। এখানে:
- সব পোস্ট দেখায় infinite scroll সহ
- Composer কম্পোনেন্ট দিয়ে নতুন পোস্ট তৈরি করে
- Stories দেখায়
- Left sidebar, Right sidebar, Header, Mobile navigation রয়েছে
- Dark mode toggle রয়েছে

### Login.tsx
লগিন পেজ। এখানে:
- ইমেইল এবং পাসওয়ার্ড ইনপুট
- ভ্যালিডেশন করে
- লগিন সাকসেস হলে ফিড পেজে রিডাইরেক্ট করে

### Register.tsx
রেজিস্ট্রেশন পেজ। এখানে:
- first_name, last_name, email, password, password_confirmation ইনপুট
- স্ট্রং পাসওয়ার্ড ভ্যালিডেশন
- রেজিস্ট্রেশন সাকসেস হলে ফিড পেজে রিডাইরেক্ট করে

### MyProfile.tsx
ব্যবহারকারীর নিজস্ব প্রোফাইল পেজ। এখানে:
- ব্যবহারকারীর তথ্য দেখায়
- শুধু নিজের পোস্ট দেখায়
- Infinite scroll সহ পোস্ট লোড করে

### PostDetail.tsx
একটি পোস্টের ডিটেল পেজ। এখানে:
- একটি সিঙ্গেল পোস্ট দেখায়
- কমেন্ট এবং রিপ্লাই দেখায়
- প্রাইভেট পোস্ট চেক করে

### Settings.tsx
সেটিংস পেজ। এখানে:
- প্রোফাইল ইনফো আপডেট করে
- পাসওয়ার্ড চেঞ্জ করে
- Tabs ব্যবহার করে UI অর্গানাইজ করে

### NotFound.tsx
404 পেজ। যখন কোন রাউট খুঁজে পায় না তখন দেখায়।

### Test.tsx

## টেকনোলজি স্ট্যাক

- **React**: UI লাইব্রেরি
- **TypeScript**: টাইপ সেফটি এর জন্য
- **Vite**: বিল্ড টুল
- **React Router**: রাউটিং
- **TanStack React Query**: ডেটা ফেচিং এবং ক্যাশিং
- **Axios**: HTTP রিকোয়েস্ট
- **SweetAlert2**: মোডাল এবং অ্যালার্ট
- **FontAwesome**: আইকন
- **Bootstrap**: CSS ফ্রেমওয়ার্ক

## আর্কিটেকচার প্যাটার্ন

1. **Component-based Architecture**: সবকিছু রিইউজেবল কম্পোনেন্ট হিসেবে ভাগ করা
2. **Separation of Concerns**: Services, Components, Pages আলাদা ফোল্ডারে
3. **Context API**: গ্লোবাল স্টেট ম্যানেজমেন্ট
4. **Custom Hooks**: রিইউজেবল লজিক
5. **Type Safety**: TypeScript ব্যবহার করে
